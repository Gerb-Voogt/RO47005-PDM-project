# RO47005 - Planning & Decision Making Project
In this project three different approaches are used and compared in the object avoidance of a car on a road. These three approaches are:
1. Local MPC with the middle of the road as reference path
2. Local MPC with a reference path generated by an RRT algorithm with motion primitives
3. Local MPC with a reference path generated by a model based trajectory optimisation

The project is divided into 5 folders:
1. SETUP: files within this folder define the scenarios and create the centerline data set and obstacles. This struct is saved in the file TestPathFixed.mat
2. ACADOS: the files in this folder perform the simulations in ACADOS. The 'main' file runs all scenarios with all three approaches and calls all other files.
3. RRT: the files in this folder perform the RRT algorithm that outputs a reference to the local MPC that is run in the main file.
4. METRICS: these files extract the metrics from the outputs of the simulations
5. VISUALIZATION: Creates an animation of the simulations
